# AIhealth-main

## 簡介
本專案旨在建置一套支援遠距復健應用之醫療資訊整合平台，功能架構參考傳統醫療資訊系統（HIS, Hospital Information System），並進一步擴充支援遠距醫療所需之角色任務互動。系統強調個人資料保護、去識別化資料處理，以及支援人工智慧（AI）模型訓練之結構化資料收集能力。

這個平台讓醫師和治療師能夠順利發布任務和問卷給個案完成，並讓醫療人員可以隨時檢查個案的完成狀況，同時醫院後端可以管理所有醫療人員。

## 各身分介紹
長照者：可檢視其協助照護之個案之任務提醒與注意事項。

個案（即復健患者）：可依照系統任務執行互動式復健與日常記錄。

家屬：可檢視任務進度，並取得經醫師核准之照護指引與技巧。

治療師（職能／物理）：可派遣復健任務，建構如「10次卧推」等回家訓練任務，支援即時姿勢偵測、異常通報等互動功能。

醫師：具更高指派與監控權限，可與治療師協同安排任務。

醫院後台：管理醫師與治療師帳號，彙整個案紀錄與數據分析（去識別化）。

系統後台：系統最上層管理者，負責B2B、B2C帳號操作權限。
## 功能
(一) 任務派遣與互動模組
治療師與醫師可指定任務，病患於家中操作並回傳動作影片。
(二) 客製化表單模組
治療師可建立並派發評估表單予個案，支援以下題型：
　1. 單選題
　2. 多選題
　3. 開放式文字題
　4. 圖像／影片上傳
　5. 圖像／影片觀察題
所有填寫紀錄可儲存並作為後續評估依據。
系統後台與醫院可以製作客製化表單給醫療人員填寫，例如醫囑表單，評估量表等客製化功能，並支援修正後再開各自給與各案填寫。
　1. 單選題
　2. 多選題
　3. 開放式文字題
　4. 圖像／影片上傳
　5. 圖像／影片觀察題
(三) 提醒與追蹤模組
系統每日提醒個案執行任務，並依任務執行情況進行追蹤回報。
(四) AI資料接口設計（僅設計資料端，AI演算法不在本階段開發範圍內）
個案回傳資料具結構化與可標註欄位設計
個人資料進行去識別化，並取得合法授權後始得作為訓練素材
(五)  前端介面設計
  1. 訂閱按鈕
  2. 上傳問卷按鈕
  3. 問卷點選按鈕
